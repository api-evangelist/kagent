The kagent team built a Go runtime alternative to its Python runtime for Kubernetes-native AI agents. Benchmarks show the Go version uses 11x less disk space, starts 6.7x faster, and consumes 36x less idle memory, making it favorable for declarative agents while Python remains better for custom logic.
